# Как прислать лица и голоса

Пришли одну папку (или архив) с такой структурой:

```
материалы/
├─ люди.csv                  ← кто есть кто (Excel/Google Sheets → «CSV, разделитель ;», UTF-8)
├─ фото/
│  ├─ ivan/                  ← папка = значение из колонки «папка»
│  │  ├─ 1.jpg               ← 1–5 фото, любое имя файла
│  │  └─ 2.jpg
│  ├─ anya/
│  │  └─ 1.jpg
│  └─ smirnov/
│     └─ 1.jpg
└─ голоса/
   ├─ go/        «Три! Два! Один! Погнали!»   — 1–10 файлов, голоса разных друзей
   └─ final/     «Всё, хватит, играем ещё» или «Кто кем был?» — для экрана разбора
```

## Таблица `люди.csv`

Колонки (первая строка — заголовок, не удаляй):

| папка | имя | тип | тег1 | тег2 | тег3 |
|---|---|---|---|---|---|
| ivan | Иван Петров | студент | Группа ИТ-21 | любитель поспать на парах | |
| anya | Аня Соколова | студент | Староста | знает всё раньше препода | |
| smirnov | Виктор Павлович Смирнов | препод | Доцент кафедры матана | строгий | ставит зачёт по списку |

- `папка` — латиницей, без пробелов; должна совпадать с именем папки в `фото/`.
- `тип` — `студент` / `друг` / `friend` или `препод` / `преподаватель` / `teacher`.
- `тег1…тег3` — до 40 символов, можно оставить пустыми.
- Имя — как его зовут в компании, до 24 символов.

## Фото

- 1–5 фото на человека: приложение выбирает одно случайно каждый раунд.
- Лучше PNG с прозрачным фоном. JPG тоже пойдёт — фон вырежется уже в приложении.
- ≥ 800×800, лицо по центру, эмоция важнее качества.
- Не сжимай через мессенджер «как документ» — присылай файлами.

## Голоса

- Формат: **m4a (AAC)** или **wav**, моно, 44.1 кГц, до 3 секунд на реплику.
- Имя файла — кто говорит: `rustam_go.m4a`, `anya_krasavchik.m4a` (латиницей или русскими буквами, без пробелов).
- Нужны 2 группы:
  1. **go** — «Три! Два! Один! Погнали!» (несколько человек — каждый раунд случайный голос);
  2. **final** — на экране разбора («Всё, хватит, играем ещё»).
- 3–6 голосов в каждой группе достаточно, чтобы игра звучала «вашей компанией».
- Если какой-то группы нет — играет встроенный звук (не тишина).

## Что произойдёт после отправки

Я запускаю `py tools/prepare_materials.py`:
1. фото режутся/уменьшаются и раскладываются в `assets/characters/<id>/`;
2. голоса копируются в `assets/voices/<slot>/`;
3. `characters.json` обновляется — имена, типы, теги, несколько фото на человека;
4. собирается новый APK, где всё уже внутри.

Ничего в коде менять не нужно. Старые заглушки, которых нет в таблице, остаются.
