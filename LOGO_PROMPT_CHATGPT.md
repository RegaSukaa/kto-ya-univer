# Промпт для ChatGPT: логотип «Кто Я: Универ»

> Просто копируй блоки по порядку в чат ChatGPT (включай генерацию картинок). Модель там —
> GPT-4o / DALL·E, поэтому: никаких `--ar` и `--no`, запреты пишутся словами, HEX держится
> «примерно». Всё остальное — ниже.

---

## 1. Основной промпт (первое сообщение, копировать целиком)

```
Сгенерируй логотип-иконку для мобильной игры. Квадратное изображение 1:1.

Что за игра: вечериночная игра «Кто Я: Универ» — игрок прикладывает телефон ко лбу, остальные
видят на экране карточку с лицом друга или преподавателя и подсказывают ему.

Знак: голова человека в профиль, упрощённая до геометрических форм, к её лбу плашмя прижат
смартфон, как повязка на голове; экран смотрит на зрителя, на экране — крупный жирный знак вопроса.

Стиль: плоская векторная графика, как аккуратная современная иконка приложения. Равномерные
толстые контуры (около 8% ширины знака), скруглённые стыки. Никаких теней, градиентов, бликов,
текстур, объёма и освещения. Знак по центру, занимает примерно 78% кадра, вокруг ровные поля.

Цвета — строго три: фон почти чёрный графит #101014; телефон и контур головы тёплый янтарный
#FFB020; знак вопроса белый #F7F7FA.

В картинке не должно быть: текста, букв, цифр, подписей, водяных знаков, фотографий,
реалистичного лица, чужих логотипов, мелких деталей и декора.

Знак должен оставаться понятным при уменьшении до 48 пикселей, поэтому минимум деталей:
без ушей, волос, шеи и пальцев.
```

## 2. Выбор направления (одно сообщение, 4 картинки)

```
Покажи 4 разных варианта знака, каждый отдельной картинкой, все в одном стиле и одной палитре:

1. голова в профиль с телефоном на лбу (как в первом варианте);
2. голова анфас, телефон лежит поперёк лица как визор, снизу широкая улыбка;
3. скошенная карточка 3:4 с силуэтом головы и огромным знаком вопроса, синий фон #2563EB;
4. знак вопроса, у которого верхняя дуга заканчивается смартфоном, а точка — короткая улыбка.

Без текста во всех четырёх.
```

Выбери один — дальше работаешь только с ним.

## 4. Векторная версия (главное — попросить код, а не картинку)

```
Теперь переведи этот знак в SVG-код: viewBox="0 0 108 108", только элементы path, circle и rect,
без текста, без встроенных растровых изображений, три цвета (#101014, #FFB020, #F7F7FA).
Знак должен занимать центральные 66×66 единиц, поля по 21 с каждой стороны — это safe zone
иконки Android. Выведи только код SVG одним блоком, чтобы я мог сохранить его в файл.
```

Затем, если нужно:

```
Сделай из этого же SVG монохромную версию: один белый цвет, только заливки, без обводок —
для тематических иконок Android 13+.
```

## 5. Вордмарк (текст — отдельно от иконки)

```
Сделай вордмарк игры: надпись «КТО Я?» крупным жирным геометрическим шрифтом капсом, белым
на графите #101014, знак вопроса янтарный, ниже мелкая подпись «УНИВЕР EDITION» с широким
трекингом. Слова строго на русском, буквы «К», «Т», «О», «Я» — кириллица. Ничего, кроме
этих слов, в картинке нет.
```

> Если буквы поехали (GPT-4o иногда рисует «KTO R») — не мучай модель: попроси SVG-код
> надписи либо ставь текст шрифтом Rubik Bold / Inter ExtraBold в редакторе.

## 6. Что важно знать про ChatGPT и не тратить попытки

- **Прозрачного фона не будет.** Проси сплошной `#101014` — фон убирается локально (Python +
  Pillow / любой редактор), иначе получишь полупрозрачные артефакты по краям.
- **HEX держится ±:** после генерации перекрась под точные значения (в SVG-версии — просто
  замени код цвета).
- **Один знак за раз.** «Сделай 4 варианта в одной сетке 2×2» даёт мешанину; проси 4 отдельных
  картинки.
- **1024×1024 — максимум картинки.** Для всех размеров иконки уменьшай сам или проси у агента
  (см. `LOGO_PROMPT.md`, раздел 7).
- **Он любит добавлять тени и градиенты.** Каждую правку начинай с «плоско, без теней и
  градиентов» — иначе через 3 шага знак снова станет «3D-пластилином».
- **Не проси фотореализм и реальные лица** — в логотипе игры живых людей быть не должно
  (ст. 152.1 ГК РФ, да и на 48 px это грязь).
- **Если модель отказывается** рисовать «человека с телефоном» (бывает из-за фильтров на
  «человек + устройство у головы») — переформулируй: «стилизованный силуэт головы»,
  «абстрактная голова-фигура», без слова «face».

## 7. Финальная проверка перед тем, как нести в проект

- [ ] Знак читается в 32–48 px (скриншот, не «на глаз»).
- [ ] Внутри круга ничего не срезается.
- [ ] Три цвета, ноль градиентов, ноль текста.
- [ ] Есть SVG-код (не только PNG).
- [ ] На светлом и тёмном фоне знак виден.
- [ ] Не похоже на лицо конкретного человека и не содержит чужих логотипов.
