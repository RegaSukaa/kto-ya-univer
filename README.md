# Кто Я: Универ Edition

Игра на Android для компании 2–10 человек: телефон идёт по кругу и показывает карточку
с лицом друга или преподавателя. Тот, кому она выпала, её не видит — остальные видят.
Дальше всё происходит вживую: игрок задаёт вопросы «да/нет», остальные отвечают.

Приложение — это только карточки и правила. Счёта, «угадал/не угадал» и победителей в нём нет.

## Как играет компания

1. Каждому выпадает персонаж; свой он не видит — телефон держат остальные.
2. Когда все посмотрели своих персонажей, игроки по очереди задают вопросы про своего.
3. Вопросы в основном такие, где отвечают «да» или «нет». «Да» — спрашиваешь дальше,
   «нет» — очередь переходит следующему.
4. Угадал, кто ты, — победа. Всё остальное — вживую.

Правила встроены в приложение: кнопка «Как играть» на главном экране и на экране состава.

## Поток экранов

`Состав` → `Передача` → отсчёт 3-2-1 → карточка (`showMs`, по умолчанию 10 с) → следующий игрок →
`Разбор`: карточки закрыты, по нажатию — отсчёт 3-2-1 и повторный показ на `showMs` →
`Отчёт в Telegram` (список «игрок — персонаж») / «Ещё раунд» / «В меню».

## Что нового в 1.4

- **Реальный банк:** 51 человек (33 студента, 18 преподавателей), 190 фото; у каждого 1–23 кадра,
  на раунд берётся случайное фото.
- **Голоса отсчёта:** 4 записи в `assets/voices/go/`, играют каждый раз перед карточкой (и перед
  повторным показом). `final` пока пуст — играет встроенный звук.
- **Громкость голосов** (старт/финал) регулируется отдельным ползунком в настройках и не влияет
  на тики и прочие звуки.
- **Механика без счёта.** Убраны «Ты угадал?», отметки, статусы и итоги с победителем.
- **Правила «да/нет»** отдельным экраном.
- **Повторный показ** из разбора начинается с отсчёта 3-2-1.
- **Яркость не меняется** во время игры; экран только не гаснет.
- **Добавление фото убрано.** Лица приходят только из `assets/` (готовит `tools/prepare_materials.py`).
- **Настройки:** убраны «Чередовать друзей и преподов» и «Отмечать результат»; раздача полностью
  случайная. Остались фильтр колоды, время показа, звук/вибрация, тема, язык.
- Голоса: только `go` (отсчёт) и `final` (разбор), случайные из банка.

## Онлайн-режим: сервер

```bash
cd server && npm i && npm start
# LAN Wi-Fi: ws://192.168.1.42:8080/ws
```

Адрес вводится в приложении («Онлайн» → «Сервер») и сохраняется. Требования: Node 20+,
телефоны и ПК в одной Wi-Fi. Локальный режим работает без сети.

## Свои лица и голоса

Инструкция и шаблон: **`materials/ШАБЛОН.md`**.

```
materials/
├─ люди.csv            папка;имя;тип;тег1;тег2;тег3
├─ фото/<папка>/       1–5 фото на человека
└─ голоса/
   ├─ go/        «Три! Два! Один! Погнали!»
   └─ final/     «Всё, хватит, играем ещё»
```

`py tools/prepare_materials.py` раскладывает фото в `assets/characters/<id>/photo_N.png`
(на каждый раунд выбирается случайное), копирует голоса в `assets/voices/<slot>/` и обновляет
`characters.json`. Затем пересборка APK.

Формат голоса: m4a (AAC) или wav, моно, 44.1 кГц, ≤ 3 с. Фото: PNG с прозрачным фоном (лучше)
или JPG. Приложение больше не импортирует фото — только готовый банк из assets.

Приоритет звука: случайный голос из банка → встроенный WAV. Тишины нет.
Отсутствующий/битый файл не роняет игру; без фото — инициалы на градиенте.

Иконка: `design/logo_source.png` → `py tools/make_icons.py` (adaptive icon, round, legacy, UI-логотип).

## Приватность и юридика

- Фото не покидают телефон. В онлайне сервер получает только имена, seed и фазы.
- Нет аналитики, рекламы, аккаунтов; `allowBackup="false"`.
- Ст. 152.1 ГК РФ: изображение гражданина охраняется. Приложение не публикуется в Google Play
  и RuStore, а раздаётся APK друзьям. Используйте фото людей, которые согласны.

## Отличия от исходного ТЗ

- **Нет счёта и отметок** — по просьбе заказчика: игра про карточки, обсуждение вживую.
- **Нет записи голоса и импорта фото в приложении** — материалы готовятся заранее и кладутся в assets.
- **Раздача без чередования типов** — полностью случайная.
- **Яркость не форсируется**, остаётся только `keepScreenOn`.
- **Повторный показ** начинается с 3-секундного отсчёта.
- **Экран итогов** — это разбор с закрытыми карточками и отчётом в Telegram.
- **ML Kit/вырезание фона убраны** — фото готовятся офлайн при импорте материалов.
- **Тайминги:** отсчёт 2800 мс (3×800 + 400), затем `showMs`.
- **Шрифт:** системный Roboto.

## Что проверено, а что нет

- **Автотесты:** раздача по seed, тайминги фаз и повторного показа, контраст, банк из assets,
  несколько фото, фильтр колоды, звук, Room/wipe, `.ktya`, рендер Home/Setup/Review/Rules,
  запуск Activity, серверные комнаты.
- **Вручную:** сборка и подпись APK, сервер, сценарий комнат двумя WS-клиентами (`server/smoke.mjs`),
  импорт материалов на тестовой папке, иконка в круглой маске.
- **Не проверено:** установка на физический телефон и живой круг — устройства нет.
