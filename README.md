# Кто Я: Универ Edition

Офлайн-игра на Android для компании 2–10 человек: телефон ко лбу, остальные подсказывают.
В колоде — карточки студентов и преподавателей с вырезанными по контуру лицами, именами и тегами.

Два режима:

1. **Локальный (один телефон).** Передача телефона → отсчёт 3-2-1 → карточка 10 секунд →
   отметка (опционально) → следующий игрок → «Разбор», где карточки закрыты и открываются
   по нажатию → итоги.
2. **Онлайн (у каждого свой телефон).** Комната по 6-символьному коду, синхронный старт,
   фото в сеть не уходят — сервер передаёт только seed, имена и отметки.

На чистой установке игра полностью играбельна: внутри APK 12 персонажей-заглушек (8 студентов,
4 преподавателя) и синтезированные звуки. Настоящие лица и голоса добавляются без правок кода.

## Сборка (Windows, без Android Studio)

## Онлайн-режим: сервер

```bash
cd server && npm i && npm start
# печатает: LAN Wi-Fi: ws://192.168.1.42:8080/ws
```

В приложении: «Онлайн» → поле «Сервер» → этот адрес → «Создать игру». Адрес сохраняется,
пересобирать APK не нужно. Требования: Node 20+, телефоны и ПК в одной Wi-Fi.
Без сервера локальный режим работает всегда — он не использует сеть.

## Свои лица и голоса

Полная инструкция и шаблон: **`materials/ШАБЛОН.md`**. Кратко:

```
materials/
├─ люди.csv            папка;имя;тип;тег1;тег2;тег3
├─ фото/<папка>/       1–5 фото на человека (png/jpg, ≥800×800)
└─ голоса/
   ├─ go/        «Три! Два! Один! Погнали!»
   ├─ guessed/   «Красавчик!», «Угадал!»
   ├─ missed/    «Эх, не угадал»
   ├─ final/     «Всё, хватит, играем ещё»
   └─ личные/    необязательно: ivan_win.m4a (реплика для конкретной карточки)
```

Импорт: `py tools/prepare_materials.py` — фото уменьшаются и раскладываются в
`assets/characters/<id>/`, голоса копируются в `assets/voices/<slot>/`, `characters.json`
обновляется. Затем `./gradlew :app:assembleDebug`.

Формат голоса: m4a (AAC) или wav, моно, 44.1 кГц, ≤ 3 с. Формат фото: PNG с прозрачным фоном
(лучше) или JPG — фон вырежется в приложении при добавлении через библиотеку.

Приоритет звука: личная реплика персонажа → случайный голос из банка → встроенный WAV.
Отсутствующий/битый файл не роняет игру; вместо фото — инициалы на градиенте.

Заглушки перегенерируются: `py tools/gen_placeholders.py`, `py tools/gen_tones.py`.

## Приватность и юридика

- Фото не покидают телефон. В онлайне сервер получает только имена, seed и отметки.
- Нет аналитики, рекламы, аккаунтов; `allowBackup="false"`.
- Ст. 152.1 ГК РФ: изображение гражданина охраняется. Игра не публикуется в Google Play и RuStore,
  а раздаётся APK друзьям. Используйте фото людей, которые согласны.

## Отличия от исходного ТЗ

- **Запись голоса убрана по просьбе заказчика:** реплики заранее записаны и лежат в assets,
  игра выбирает случайный голос. Разрешение `RECORD_AUDIO` не запрашивается.
- **ML Kit:** артефакта `com.google.mlkit:subject-segmentation` не существует; используется
  `com.google.android.gms:play-services-mlkit-subject-segmentation:16.0.0-beta1`. Без GMS/модели —
  фолбэк-кроп.
- **`order[]` в онлайн-протоколе не передаётся:** сервер не знает колоду, клиенты раздают по seed.
- **Тайминги:** 3×800 + 400 = 2800 мс отсчёт, дальше `showMs` (в ТЗ тест противоречил таблице).
- **Шрифт:** системный Roboto вместо Rubik.
- **Скриншоты** отрисованы из настоящего Compose-кода через Robolectric, не с телефона.

## Что проверено, а что нет

- **Автотесты:** раздача по seed, тайминги, контраст 6 пресетов, банк из assets, несколько фото
  на человека, фильтр колоды, приоритет звука, Room/wipe, `.ktya`, рендер S2/S4/S6/S8, запуск
  Activity, серверные правила комнат.
- **Вручную:** сборка и подпись APK, запуск сервера, сценарий комнат двумя WS-клиентами
  (`server/smoke.mjs`, 12/12), импорт материалов на тестовой папке.
- **Не проверено:** установка на физический телефон и живой круг — устройства нет.
  Чек-лист ниже.

## Чек-лист на телефоне

- [ ] Установить APK: онбординг → «Играть с заглушками» → 12 карточек с лицами.
- [ ] 3 игрока: слышны отсчёт, тики последних 3 секунд, «дзынь» в конце.
- [ ] Имя читается с 2.5 м, экран не гаснет, яркость максимальная.
- [ ] «Угадал» / «Не угадал» — разные звуки и вибрация.
- [ ] «Разбор»: карточки закрыты, по нажатию открывается персонаж; долгое нажатие меняет результат.
- [ ] Итоги: персонажи скрыты, «Посмотреть персонажа «Имя»» открывает карточку.
- [ ] Фильтр «Только преподы»: в игре только преподаватели, при нехватке — предупреждение.
- [ ] Несколько фото на человека: в разных раундах попадаются разные.
- [ ] Свернуть приложение в показе → вернуться: фаза актуальная.
- [ ] Авиарежим: локальная игра работает; онлайн пишет «Нет связи».
- [ ] Добавить своё фото из галереи: кроп, «Вырезать фон», сохранение.
- [ ] Голоса из `assets/voices/go/` играют случайно (если банк заполнен).
- [ ] «Стереть мои данные» → библиотека пустеет, после перезапуска возвращаются заглушки.
- [ ] Онлайн: сервер на ПК, два телефона в одной Wi-Fi, комната по коду.
