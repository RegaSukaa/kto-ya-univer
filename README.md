# Кто Я: Универ Edition

Офлайн-игра на Android для компании 2–10 человек: телефон ко лбу, остальные подсказывают.
В колоде — карточки друзей и преподавателей с вырезанными по контуру лицами, именами и тегами.

Два режима:

1. **Локальный (один телефон).** Передача телефона → отсчёт 3-2-1 → карточка 10 секунд →
   отметка (опционально) → следующий игрок → «Разбор», где любую карточку можно показать снова →
   итоги.
2. **Онлайн (у каждого свой телефон).** Комната по 6-символьному коду, синхронный старт,
   фото в сеть не уходят — сервер передаёт только seed, имена и отметки.

Игра полностью играбельна на чистой установке: внутри APK лежит банк из 12 персонажей-заглушек
(8 друзей, 4 препода) и синтезированные звуки. Настоящие лица и голоса подставляются позже по
тем же именам файлов — код менять не нужно.

## Что внутри

```
android/    Kotlin 2.0.21 + Jetpack Compose, Room, Coil, ML Kit subject-segmentation
server/     Node 20 + ws, комнаты в памяти (без БД и без фото)
tools/      gen_placeholders.py, gen_tones.py, check_strings.py
sets/       пример набора .ktya
docs/       TIMINGS.md, DESIGN.md, QA.md, экраны в docs/screens
```

## Сборка (Windows, без Android Studio)

Портативный тулчейн: JDK 17 + Android cmdline-tools + Gradle 8.10.2.

```bash
export JAVA_HOME="C:/Users/<user>/AppData/Local/atc/jdk-17.0.21+9"
export ANDROID_HOME="C:/Users/<user>/AppData/Local/atc/android-sdk"
export PATH="$HOME/AppData/Local/atc/bin:$PATH"
cd android
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug --console=plain
```

`android/local.properties` (не коммитится): `sdk.dir=C:/Users/<user>/AppData/Local/atc/android-sdk`.

APK: `android/app/build/outputs/apk/debug/app-debug.apk` — подписан ключом `android/debug.keystore`
(лежит в репозитории, чтобы обновления ставились поверх без «Приложение не установлено»).

Проверка подписи:

```bash
"$ANDROID_HOME/build-tools/35.0.0/aapt2.exe" dump badging android/app/build/outputs/apk/debug/app-debug.apk | head -5
"$ANDROID_HOME/build-tools/35.0.0/apksigner.bat" verify --print-certs android/app/build/outputs/apk/debug/app-debug.apk
```

## Тесты

```bash
cd android && ./gradlew :app:testDebugUnitTest      # 42 теста: Logic, Room/Robolectric, рендер Compose
cd server  && npm i && npm test                      # 10 тестов комнат
py tools/check_strings.py                            # ключи ru == en
```

## Онлайн-режим: сервер

```bash
cd server
npm i
npm start        # http://0.0.0.0:8080, ws://<ip>:8080/ws
```

Сервер печатает LAN-адреса, например `LAN Wi-Fi: ws://192.168.1.42:8080/ws`.
В приложении: «Онлайн» → поле «Сервер» → вставь этот адрес → «Создать игру».
Адрес сохраняется в настройках, пересобирать APK не нужно.

Требования: Node 20+, телефоны и ПК в одной Wi-Fi. Без сервера локальный режим работает всегда —
он вообще не использует сеть.

## Как подставить свои лица и голоса (4 шага)

1. Положи фото `friend_ivan.png` в `android/app/src/main/assets/characters/` — PNG с прозрачным
   фоном, ≥ 800×800, лицо по центру, лучше смешная эмоция.
2. Положи голос `friend_ivan_win.m4a` в `android/app/src/main/assets/sounds/` (AAC, ≤ 3 с) — этим
   голосом игра скажет «Красавчик!» именно на этой карточке. Без файла играет общий `win.wav`.
3. Новый человек — добавь объект в `android/app/src/main/assets/characters.json`
   (`id, name, kind, tags, photo, initials`).
4. `./gradlew :app:assembleDebug` — APK уже с настоящими лицами. Код не меняется.

Отсутствующий или битый файл не роняет игру: вместо фото — инициалы на градиенте, вместо голоса —
голосовой пак, вместо него — встроенный WAV. Тишины нет ни в одной фазе.

Заглушки перегенерируются: `py tools/gen_placeholders.py` и `py tools/gen_tones.py`.

## Приватность и юридика

- Фото не покидают телефон. В онлайн-режиме сервер получает только имена, seed и отметки.
- Нет аналитики, рекламы, аккаунтов; `allowBackup="false"`.
- Ст. 152.1 ГК РФ: изображение гражданина охраняется. Поэтому игра не публикуется в Google Play
  и RuStore, а раздаётся APK друзьям. Используйте фото людей, которые согласны.

## Что проверено, а что нет

- **Проверено автотестами:** раздача по seed, тайминги фаз, контраст всех 6 пресетов, наполнение
  банка из assets, фолбэк на инициалы, приоритет звука, CRUD и «стереть данные», экспорт/импорт
  `.ktya`, рендер S2/S4/S6/S8, серверные правила комнат.
- **Проверено вручную:** сборка APK, подпись, запуск сервера, сценарии комнат через WS-клиент,
  скриншоты экранов отрисованы из настоящего кода (`docs/screens`).
- **Не проверено:** установка на физический телефон и прохождение полного круга вживую —
  устройства в этой среде нет. Ниже чек-лист для 10 минут на телефоне.

## Чек-лист на телефоне

- [ ] Установить APK, открыть: онбординг → «Играть с заглушками» → в библиотеке 12 карточек с лицами.
- [ ] 3 игрока, показ 10 с: слышны отсчёт, тики на последних 3 секундах, «дзынь» в конце.
- [ ] Телефон ко лбу: имя читается с 2.5 м, экран не гаснет, яркость максимальная.
- [ ] Отметка «Угадал» → «Красавчик!», «Не угадал» → «Эх, не угадал», вибрация разная.
- [ ] «Разбор»: тап по карточке показывает её снова; долгое нажатие меняет результат.
- [ ] 10 игроков: сетка разбора скроллится, кнопки не перекрывают последний ряд.
- [ ] Свернуть приложение в показе → вернуться: фаза актуальная, таймер не сбросился.
- [ ] Авиарежим: локальная игра работает; онлайн пишет «Нет связи».
- [ ] Добавить своё фото из галереи: кроп, «Вырезать фон», превью карточки, сохранение.
- [ ] Записать голос в «Голос группы» → он играет в игре.
- [ ] «Стереть мои данные» → библиотека пустеет, после перезапуска возвращаются заглушки.
- [ ] Онлайн: сервер на ПК, два телефона в одной Wi-Fi, комната по коду, синхронный старт.
