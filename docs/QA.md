# QA: ручная проверка

## Полный круг

1. Чистая установка → онбординг → «Играть с заглушками».
2. В библиотеке 12 карточек: у каждой лицо (круг с инициалами), имя, теги.
3. «Играть на одном телефоне» → 3 игрока → показ 10 с → «Поехали».
4. Каждый игрок: «Готово» → отсчёт с писком и вибрацией → карточка.
5. После третьего — «Разбор»: 3 карточки, тап показывает повторно, долгое нажатие меняет статус.
6. «Закончить игру» → итоги.
7. Повторить с включённой отметкой «Отмечать результат после показа».

## Крайние случаи

| Случай | Ожидание |
|---|---|
| 2 игрока | сетка из 2 карточек по центру, не растянута |
| 10 игроков | сетка скроллится, нижняя панель не перекрывает последний ряд |
| 1 персонаж | «Поехали» неактивна, плашка «Нужно минимум два персонажа» |
| имя 24 символа + 3 тега | ничего не выходит за карточку, имя уменьшается |
| нет/битое фото | инициалы, бейдж «нет фото» |
| сегментация упала | прямоугольный кроп, игра играбельна |
| свернуть в показе | при возврате актуальная фаза, таймер не сброшен |
| звонок в показе | раунд не сбрасывается, звук возвращается |
| звук выключен в системе | тонов нет, вибрация работает |
| поворот экрана | Activity портретная, таймер не ломается |
| комната не существует | «Комната не найдена», поле кода редактируется |
| имя занято | «Такое имя уже занято» |
| хост закрыл приложение | через 60 с комната закрыта, у остальных «Игра закончилась» |
| разные наборы | баннер «персонажи могут отличаться», игра идёт |
| часы сбиты на 5 минут | коррекция по серверу, при > 2 с баннер |
| двойной тап «Начать» | второй `start` игнорируется |
| «Стереть данные» | карточки, фото, пресеты и записи удалены |
