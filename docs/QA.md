# QA: ручная проверка

## Полный круг

1. Чистая установка → онбординг → «Играть с заглушками».
2. В библиотеке 51 карточка: лицо, имя, теги; карточка открывается по нажатию (просмотр).
3. «Как играть» — правила про вопросы «да/нет».
4. «Играть на одном телефоне» → 3 игрока → показ 10 с → «Поехали».
5. Каждый игрок: «Готово» → отсчёт → карточка. После карточки сразу следующий игрок.
6. После третьего — «Разбор»: карточки закрыты, статусов нет.
7. Нажать карточку → отсчёт 3-2-1 → карточка на 10 с → возврат в разбор.
8. «Отчёт в Telegram» → открывается Telegram с текстом «игрок — персонаж».
9. «Ещё раунд» → новая раздача, те же игроки.

## Крайние случаи

| Случай | Ожидание |
|---|---|
| 2 игрока | сетка из 2 карточек, не растянута |
| 10 игроков | сетка скроллится, кнопки не перекрывают последний ряд |
| 1 персонаж в фильтре | «Поехали» неактивна, причина подписана |
| имя 24 символа + 3 тега | ничего не выходит за карточку |
| нет/битое фото | инициалы, бейдж «нет фото» |
| несколько фото | в разных раундах разные, в разборе то же, что в раунде |
| свернуть в показе | при возврате актуальная фаза |
| звонок в показе | раунд не сбрасывается, звук возвращается |
| звук выключен в системе | тонов нет, вибрация работает |
| поворот экрана | Activity портретная |
| комната не существует | «Комната не найдена» |
| разные наборы | баннер «персонажи могут отличаться» |
| «Стереть данные» | карточки, фото и пресеты удалены |
