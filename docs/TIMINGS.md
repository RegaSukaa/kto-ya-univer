# Тайминги

Считаются от `SystemClock.elapsedRealtime()`, шаг кадра 100 мс.

| Фаза | Длительность | Что видно | Звук |
|---|---|---|---|
| Передача | до тапа | имя игрока, «Готово» | нет |
| Отсчёт | 3×800 + 400 = **2800 мс** | 3 → 2 → 1 → «Погнали!» | писки / случайный голос из банка |
| Показ | `showMs` (10 000 по умолчанию) | карточка, обод, цифры | тики 3/2/1, «дзынь» на 0 |
| Разбор | до действия | закрытые карточки | случайный голос `final` |
| Повторный показ | **2800 мс отсчёт** + `showMs` | 3-2-1, затем карточка | писки, тики, «дзынь» |

Границы: PASS 0 → COUNTDOWN 0…2800 → SHOW 2800…12800 → следующий PASS или REVIEW.
При `showMs = 5000` показ заканчивается на 7800 мс. Проверено `TimingTest`.

Особенности:
- Отсчёт не подстраивается под длину голосового файла: ритм фиксирован, звук доигрывает.
- Свёрнутое приложение не сбрасывает раунд: при возврате актуальная фаза.
- «Назад» в отсчёте/показе перехватывается диалогом «Отменить показ?».
