# Тайминги (жёсткие)

Всё считается от `SystemClock.elapsedRealtime()`, шаг кадра 100 мс (не цепочка `delay(1000)`).

| Фаза | Длительность | Что видно | Звук | Вибрация |
|---|---|---|---|---|
| S3a Передача | до тапа | имя игрока, «Возьми телефон…» | нет | 30 мс при входе |
| S3b Отсчёт | 3×800 + 400 = **2800 мс** | 3 → 2 → 1 → «Погнали!» | писк на каждый шаг; голосовой пак вместо писков | 3 коротких + длинная |
| S4 Показ | `showMs` = 10 000 | карточка, обод, цифры | тики 3/2/1 с (громкость растёт), «дзынь» на 0 | парные импульсы последние 3 с |
| S5 Отметка | до тапа | «Ты угадал?» | «Красавчик!» / «Эх, не угадал» | успех = один длинный, провал = два коротких |
| S6 Разбор | до действия | сетка карточек | тихий клик | — |
| S7 Повторный показ | `showMs` | та же карточка + крестик | тики, без голосового отсчёта | — |
| S8 Итоги | до действия | счёт, лучший, список | фанфары | — |

Границы фаз (проверено `TimingTest`): PASS 0 → COUNTDOWN 0…2800 → SHOW 2800…12800 →
следующий PASS (или MARK при включённой отметке). При `showMs = 5000` показ заканчивается на 7800 мс.

Особенности:
- Отсчёт не подстраивается под длину записанного файла: визуальный ритм фиксирован, звук доигрывает.
- Свёрнутое приложение не сбрасывает раунд: при возврате показывается актуальная фаза (или отметка,
  если время вышло).
- Кнопка «Назад» в отсчёте/показе перехватывается диалогом «Отменить показ?».
